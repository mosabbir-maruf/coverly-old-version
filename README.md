# **Coverly - Cover Page Generator (Basic Version)**

**Coverly** is a simple tool that allows you to generate academic cover pages for **assignments** and **lab reports**. This basic version uses **HTML**, **CSS**, and **Python Flask** for the backend.

## **Features:**
- Simple HTML and CSS design.
- Python Flask backend to generate cover pages.
- Responsive design for both desktop and mobile.
